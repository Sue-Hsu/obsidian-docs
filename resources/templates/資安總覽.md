## 5. 機密保護、原始報告與受控證據管制 (Confidentiality & Evidence Control)

本專案遵循 ISO 27001 資訊資產保護原則，所有資安筆記均實施以下受控管理：
- 密等分級治理：
  - 脫敏資安摘要預設為「內部使用」。
  - 凡筆記內容包含具體可利用弱點 PoC、真實帳戶資訊、內部網路拓撲或敏感系統路徑時，密等必須強制標定為「機密」。
  - 對外版本必須另行於 `50 專案文件/05 對外發布/` 產出，嚴格完成去識別化脫敏與發布審查後始得標為「公開」。
- 原始掃描報告受控存放：
  - 儲存位置優先級：原始掃描報告（如工具 Raw JSON/XML、DAST 請求封包、Burp/ZAP Session）優先保存在 Git repo 與 Obsidian Vault 之外的獨立受控儲存區。
  - Repo 內存放限制：若暫存於 repo 內，須確認已排除於 Git、建置產物及部署內容，並移除 Cookie、token、Session、私人郵件、帳戶識別資訊 (PII) 及完整原始 HTTP 請求/回應封包。
  - Vault 留存邊界：Vault 內只保留脫敏摘要、檔案完整性雜湊 (SHA-256)、保存期限與受控位置說明。
- 安全清理與銷毀：
  - 保存期限：依專案稽核週期保存（預設 90 天）。
  - 清理方式：期滿清理時，依儲存媒體與平台採用可驗證的永久刪除、加密金鑰銷毀或組織核准的資料清理程序。
